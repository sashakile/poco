Core architecture decisions: (1) Lazy-first evaluation — operations build expression trees, collect() materializes. (2) Column-primary storage, row access as view. (3) Symbolic column accessors (_.col), no strings. (4) Pipe composition via | operator. (5) Swappable Storage + Compute backends via protocols. (6) Both mutable/immutable paths — performance decides default. (7) Strict errors: raise early, no silent coercion. (8) Both dict and row-based DataFrame construction. (9) Property-based testing (hypothesis) for algebraic laws + example-based pytest.
