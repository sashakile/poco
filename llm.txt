# poxo (poco)

> Pequeño y perezoso panda — Small and lazy panda

poxo is a pure Python DataFrame library for small exploratory and teaching
examples. It is not a pandas clone — it identifies the true abstract interfaces
needed for data operations, grounded in category theory.

## Design Principles

- **Lazy-first**: operations build expression trees, materialized on demand
- **Algebraic**: operations follow Spivak's Σ ⊣ Δ ⊣ Π adjoint triple
- **Composable**: pipe syntax via `|` operator, transducer-inspired pipelines
- **Swappable**: abstract Storage and Compute backends (pure Python default)
- **Strict**: raises early on errors, no silent coercion
- **Pure Python**: no required dependencies

## Architecture

- Schema = category, DataFrame = functor from schema to Set
- Lazy IR (expression trees as free monad) enables backend-agnostic optimization
- Column-primary storage, row access as view
- HAMT for structural parts, contiguous arrays for data
- Symbolic column references (`_.col`), no strings

## Core Operations (Σ ⊣ Δ ⊣ Π)

- **Δ (pullback)**: select, project, rename — structural transformations
- **Σ (left Kan extension)**: groupby, aggregate, combine — summarization
- **Π (right Kan extension)**: join, normalize — relational composition

## Usage

```python
import poxo as po

df = po.DataFrame({"name": ["Ana", "Luis"], "age": [30, 25]})
result = df | po.where(_.age > 25) | po.select(_.name)
```
